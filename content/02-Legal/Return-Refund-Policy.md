# Return & Refund Policy (Internal Record)

- **Document ID**: LP-RR-001
- **Version**: 1.0
- **Created Date**: July 19, 2026
- **Status**: Active

## Purpose

This document records Nuri's return and refund policy for internal reference and alignment with the
public-facing policy at `/refund`.

## Summary

- **No refunds or returns.** All sales are final once the order has been processed/shipped.
- **Order cancellation is available only while the order is still being processed** — i.e. order
  status is `pending`, `confirmed`, or `processing`. Once `shipped`, cancellation is not possible.
- Cancellation is free; request via hello@nuri.com with order number and "Cancel".
- Defective/incorrect items are reviewed case-by-case (no automatic refund).

## Alignment

This internal record must match the published `/refund` page. Update both together when changed.
